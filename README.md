# Charming

**Charming** is a free, open-source JavaScript library for creative coding and data-driven drawing. It has two parts:

- **[Charming Core](https://charmingjs.org/flow)**, a declarative language for drawing shapes from data, with renderers for [Canvas](https://charmingjs.org/flow#cm-canvas), [WebGL](https://charmingjs.org/webgl) and [the terminal](https://charmingjs.org/terminal) (ASCII art).
- **Helpers** for working with [SVG and HTML](https://charmingjs.org/dom), [Canvas](https://charmingjs.org/canvas), [paths](https://charmingjs.org/path), [text](https://charmingjs.org/pretext), [vectors](https://charmingjs.org/vector) and [noise](https://charmingjs.org/noise) directly, with little boilerplate.

Both are designed to work alongside other libraries such as [D3](https://d3js.org/) and [p5](https://p5js.org/), and can be adopted independently.
